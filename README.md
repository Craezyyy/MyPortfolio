# Austin Concepcion — portfolio

A single-page portfolio with selected software and data work. The site uses plain HTML, CSS, and a small amount of JavaScript; there are no dependencies or build steps.

## Publish with GitHub and Vercel

1. Create a new GitHub repository.
2. Upload `index.html` and `README.md` to the repository root (extract this ZIP first if necessary).
3. In Vercel, choose **Add New → Project**, import that repository, and deploy it. If prompted for a framework, choose **Other** and leave the build command blank.

To edit the portfolio, change `index.html` and commit it to the repository. Update the project links and contact information there as your work evolves.
