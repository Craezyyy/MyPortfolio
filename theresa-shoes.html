Business question

How can a local shoe retailer manage made-to-order requests, inventory, and sales without relying on scattered manual records?

Analysis & approach

Our team mapped the ordering and administrative workflow, then developed a centralized system with role-based access. My resume describes the client desktop application as an Electron frontend backed by a REST API and automated database migrations. The public showcase is a React/Vite web demo of the ordering experience and admin tools.

What this work provides

The result is a connected workflow for orders, inventory, and sales, with an administrative view for catalog, payments, and company records. The public demo uses sample-safe access and hides the owner’s contact details; it is a showcase rather than the client’s production environment.
