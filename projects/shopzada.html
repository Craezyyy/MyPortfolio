ShopZada: Enterprise Data Warehouse & BI Pipeline

Consolidated fragmented, multi-department e-commerce data into a centralized analytical warehouse using Kimball dimensional modeling, automated Python ETL pipelines, Apache Airflow orchestration, and Power BI dashboards.

1. The Problem & Business Context

ShopZada is an e-commerce platform processing hundreds of thousands of transactions. Its operations spanned multiple departments—including customer management, catalog teams, marketing, and warehouse logistics—each storing data in isolated, incompatible formats (CSV, JSON, Excel, and raw Parquet).

This fragmentation created serious operational blind spots: conflicting metrics across teams, manual data reconciliation delays, and an inability to accurately evaluate promotional campaign effectiveness or customer lifetime value.

2. System Architecture & Engineering Pipeline

As part of our data engineering consultant team, I helped design and build a 5-tier analytics pipeline:

  • Immutable Raw Layer: Ingested untouched source datasets across 5 departments to guarantee full auditability and traceability back to original transactions.
  • ETL & Staging Layer: Developed Python/pandas pipelines that normalized irregular schemas, enforced strict data types, stripped invalid records, and exported cleaned outputs into efficient, compressed Parquet files.
  • Kimball Dimensional Model: Designed a resilient star schema inside PostgreSQL. Separated business events into transactional fact tables (fact_orders, fact_order_items) connected to clean dimensions (dim_customer, dim_product, dim_campaign, dim_merchant, dim_date).
  • Orchestration & Containerization: Built an automated Apache Airflow DAG managing execution order and staging dependencies, fully containerized alongside PostgreSQL using Docker Compose.
  • Analytics Aggregation: Engineered automated transformation scripts (create_dashboard_csvs.py) generating summarized business metrics for direct Power BI consumption.

4. Key Engineering Deliverables

  • Automated Ingestion & Quality Checks: Built schema validation routines that check for null business keys, missing column headers, and row count discrepancies between pipeline stages.
  • Production-Grade Star Schema: Implemented SCD Type 1 dimensions allowing complex multi-table joins without performance degradation.
  • Airflow Task Dependency Management: Configured deterministic DAG tasks to guarantee parent tables finish staging before downstream fact tables process.
  • Executive Decision Dashboards: Translated raw log files into clear visual KPIs highlighting seasonal peaks, customer tier spending, and campaign ROI.
